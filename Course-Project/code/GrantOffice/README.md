# GrantOffice application

Integrated Research Grant Management System, Team 13, KLE Technological University.

See the [submission README](../../../README.md) for team details, measured results, assignments and exact repository-root commands. The complete application remains here, including the original college catalog, source records, fixtures, UI, tests and launchers.

On Windows, run `start.bat` here. It uses this directory's `.venv`, creates missing accounts without replacing existing accounts, and starts http://127.0.0.1:8000. First installation uses `setup.bat` and the supplied lock. Initial passwords are in the ignored local `runtime/FIRST_LOGIN.txt`. Preserve `runtime/` when upgrading.
