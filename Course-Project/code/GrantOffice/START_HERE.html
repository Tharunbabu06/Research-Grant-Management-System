Grant Office — College Edition 2.0

Faculty login recovery

Stop the server, run reset_faculty_password.bat, enter a new password twice, then restart start.bat. Sign in as faculty with the new password. Your proposals and approvals are retained.

Start or upgrade

New installation: install Python 3.12, extract the full ZIP and run start.bat. Initial passwords are in runtime/FIRST_LOGIN.txt.

Existing installation: keep the old folder, extract this release separately and run import_previous_data.bat before starting it. Never delete runtime to repair login.

Open the dashboard

Connect the local LLM

Install/start Ollama, then run setup_llm.bat. In Office settings, check the model connection and click Test model response. Model weights download separately; no paid API key is required.

Check all fourteen software labs

Run verify_14_labs.bat and open Worklet verification in the dashboard. Genuine agency documents, institutional acceptance and live model quality remain separate human checks.

Institutional is the default workspace. Synthetic sample data stays in the separate practice workspace and cannot authorize an external submission.
